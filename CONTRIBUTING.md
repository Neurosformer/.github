# Contributing

Thank you for your interest in Neurosformer projects.

These repositories currently describe product direction and early-stage planning. Contributions should be aligned with the product scope, safety boundaries, and implementation direction described in each repository README.

## How to Contribute

1. Open an issue describing the change, question, or proposal.
2. Keep proposals specific and tied to a real workflow or user need.
3. For code contributions, open a pull request with a clear summary and testing notes.
4. Avoid adding unsupported claims, unsafe AI behavior, or unverified medical/agricultural advice.

## Product Principles

- Build workflow automation, not generic AI demos.
- Keep humans in the loop for regulated or high-risk decisions.
- Use citations, confidence scores, and audit logs where decisions depend on source material.
- Respect privacy, security, and data-protection requirements.
- Prefer narrow validated MVPs over broad unfocused feature sets.
