# Security Policy

Neurosformer products may involve sensitive documents, healthcare workflows, compliance evidence, and operational data. Security reports are taken seriously.

## Reporting a Vulnerability

If you discover a security issue, do not open a public issue. Email details to [neurosformer@gmail.com](mailto:neurosformer@gmail.com).

Please include:

- A clear description of the issue
- Steps to reproduce, if applicable
- Affected repository or component
- Potential impact
- Suggested fix, if known

We will review the report and respond as soon as practical.

## Scope

Public repositories in the Neurosformer GitHub organization are in scope unless marked otherwise.

## Safe Harbor

Good-faith security research is welcome when it avoids data destruction, privacy violations, service disruption, and unauthorized access to third-party systems.
